# SENTRY: Research Security Anomaly Detection Toolkit

SENTRY is an interactive AI-assisted research security analysis dashboard designed to support anomaly triage, metadata inspection, and human-in-the-loop review workflows using synthetic research metadata.

## Overview

This project explores how anomaly scoring, explainable signals, and visualization workflows can assist analysts in identifying potentially anomalous research activity across large-scale research ecosystems.

The platform provides:

* Author-level anomaly analysis
* Explainable triage cues and risk signals
* Interactive dashboards for flagged case review
* Metadata-driven anomaly scoring
* Human-in-the-loop review workflows

This project represents an early research prototype exploring AI-assisted research security analysis and anomaly triage workflows, with future research directions planned for submission to security-focused academic venues.

## Features

* Interactive Streamlit dashboard
* Explainable anomaly scoring
* Synthetic metadata analysis
* Author and document triage views
* Rule-based and metadata-based signal inspection
* Risk categorization workflows

## Tech Stack

* Python
* Streamlit
* Pandas
* Plotly
* LLM-assisted analysis pipelines
